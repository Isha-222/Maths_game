---Maths Invaders---

How to Run This Program
------------------------

Step 1: Install the required library
    Open terminal / command prompt and run:
        pip install pygame

Step 2: Make sure the following files are in the same folder as the game:
        - maths_invaders_final.py
        - main.py
        - player.py
        - alien.py
        - laser.py
        - obstacle.py
        - Pixeled.ttf
        - Commodore_Pixelized.ttf
        - images (folder)

Step 3: Open the file named maths_invaders_final.py

Step 4: Run the program using:
        python maths_invaders_final.py

Step 5: Follow the on-screen instructions to play.
        - Click START to choose a topic and difficulty.
        - Enter your name to save your score.
        - Use LEFT/RIGHT arrows to move and SPACE to shoot.
        - Answer maths questions when you run out of ammo.
        - View saved scores from the LEADERBOARD button on the home screen.
        - Click HOW TO PLAY for full instructions.

Note:
-----
- Scores are saved automatically to leaderboard.txt in the same folder.
- Requires Python 3 and the pygame library (see Step 1).
